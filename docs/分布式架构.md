# NetOps 分布式部署架构文档

## 1. 架构概述

NetOps 网络运维监控平台采用 **级联式分布式架构**，支持总部（L0）→ 省级（L1）→ 地市级（L2）多级部署，本地采集、上级汇总。

```
┌─────────────────────────────────────────┐
│  L0 总部中心（总库 + MQTT Broker）       │
│  - 汇总所有下级节点数据                   │
│  - 全局拓扑 / 告警 / 报表                 │
└──────────────┬──────────────────────────┘
               │ MQTT 上报 / REST 拉取
   ┌───────────┼───────────┐
   ▼                       ▼
┌────────┐            ┌────────┐
│ L1 省A │            │ L1 省B │
└───┬────┘            └───┬────┘
    │                     │
  ┌─┴─┐                 ┌─┴─┐
  ▼   ▼                 ▼   ▼
 L2  L2               L2  L2
```

## 2. 节点模型

| 字段 | 说明 |
|---|---|
| node_id | 节点唯一标识（UUID） |
| name | 节点名称（如"新疆电力"） |
| level | 层级：L0/L1/L2 |
| parent_id | 上级节点 ID |
| addr | 节点地址（域名或 IPv4） |
| token | 节点独立接入密钥 |
| online | 在线状态 |
| last_seen | 最后心跳时间 |

## 3. 部署模式

初始化时或系统设置中可切换：

- **单机模式（standalone）**：所有数据存本地 SQLite/MySQL，无上报
- **分布式模式（distributed）**：本地采集后通过 MQTT 上报上级，同时接收下级上报

切换后需重启系统生效。

## 4. 数据流向

1. **采集层**：各节点通过 SNMP/ICMP/SSH 采集本机设备、容器、数据库指标
2. **本地存储**：指标写入本地时序库（内置/TDengine）
3. **上报层**：本地数据按 node_id 标记后，通过 MQTT 主题上报上级
4. **汇总层**：上级节点订阅下级主题，写入总库
5. **查询层**：总部用户可查全部；分部用户仅查本节点及下级（NodeScope 权限隔离）

## 5. 节点分组

- 支持预建分组（如"华北分部""华南分部"）
- 下级节点可手动或自动归入分组
- 总部视图按分组聚合统计

## 6. 认证与安全

- 上下级通信使用 **节点独立 token**（非全局共享）
- MQTT 支持 TLS
- JWT Claims 携带 NodeScope，查询自动过滤
- 敏感操作（删除/回滚/重置密码）二次确认 + 审计日志

## 7. 数据库支持

- 业务库：SQLite / MySQL / PostgreSQL / 人大金仓（国产化）
- 时序库：内置内存 / TDengine / InfluxDB
- 所有数据库类型在"数据库迁移"页面切换，保存后自动重启

| 端口 | 用途 |

## 9. 部署方式

- **Windows**：解压 zip → 运行 start.bat
- **Linux**：解压 tar.gz → chmod +x install.sh → ./install.sh install
