# NetOps v2.1 运维增强范围

## 目标
减少人工操作，提升运维效率。

## 已实现（v2.1.0 ~ v2.1.4）

### 设备批量管理
- [x] 资源管理页 CSV 模板下载与导入
- [x] 设备分组自动归集
- [x] 批量启用/禁用（后续版本）

### 告警收敛
- [x] 同设备同指标抑制（overSince map）
- [x] 告警风暴合并（Notify 去重）
- [x] 节点离线告警评估
- [ ] 未确认自动升级通知（后续）

### 通知渠道
- [x] 邮件 SMTP
- [x] 企业微信 Webhook
- [x] 钉钉 Webhook
- [x] 飞书 Webhook
- [x] 通用 Webhook
- [ ] 失败重试（后续）

### 巡检报告
- [x] 日报/周报/月报自动生成
- [x] 真实 PDF 二进制（wkhtmltopdf）
- [x] 链路/服务器/数据库/容器汇总
- [x] PDF 下载不改变前端布局

### 配置只读审计
- [x] 设备运行配置定期备份
- [x] 差异对比
- [ ] 配置下发（暂不做，安全考虑）
