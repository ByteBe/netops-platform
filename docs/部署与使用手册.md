# NetOps 网络运维监控平台 — 部署与使用手册

> 版本：v2.1.9　适用系统：Linux x86_64 / ARM64（含麒麟、统信 UOS）、macOS、Windows



***

## 一、系统简介

NetOps 是一体化网络运维监控平台，功能模块：



| 模块    | 说明                                                             |
| ----- | -------------------------------------------------------------- |
| 设备监控  | SNMP/ICMP/Ping 采集设备状态、端口、流量                                    |
| 链路检测  | 链路连通性、丢包、延迟监控与阈值告警                                             |
| 数据库监控 | MySQL、PostgreSQL、Oracle、达梦、TDengine 实例存活 / 连接数 / 容量 / CPU / 内存 |
| 日志中心  | 设备日志（Syslog）+ 采集任务日志查询                                         |
| 告警中心  | 阈值告警、告警规则、通知渠道                                                 |
| 通知渠道  | 邮件（SMTP）、Webhook 等，所有规则统一发送                                    |
| AI 巡检 | 自动生成巡检报告（周 / 月报可扩展）                                            |
| 节点管理  | 多级节点注册、MQTT 上报、级联转发                                            |
| 配置备份  | 网络设备配置自动备份与对比                                                  |
| 系统管理  | 用户、角色、通知渠道、在线更新                                                |

## 二、运行环境要求

### 2.1 最低硬件



| 项目  | 最低                                    | 推荐                           |
| --- | ------------------------------------- | ---------------------------- |
| CPU | 2 核                                   | 4 核                          |
| 内存  | 2 GB                                  | 4 GB                         |
| 磁盘  | 20 GB                                 | 50 GB（日志 / 时序数据较多时建议 100 GB） |
| 网络  | 可被监控设备可达 SNMP (161)/ICMP/Syslog (514) | 同左                           |

### 2.2 操作系统



* CentOS 7+ / RHEL 7+ / Ubuntu 20.04+ / Debian 10+

* 麒麟 Kylin V10、统信 UOS V20（ARM/x86）

* 需要 `systemd`、`unzip`、`curl`

### 2.3 必需外部软件

NetOps 主程序为单一 Go 二进制，**自带 SQLite 和内置时序库**，开箱即用。生产环境建议安装：



| 软件               | 用途                  | 是否必需              | 默认版本建议             |
| ---------------- | ------------------- | ----------------- | ------------------ |
| **MySQL 8.0**    | 主业务数据库（设备、告警、用户、日志） | 生产必需，可先用内置 SQLite | 8.0+               |
| **TDengine 3.x** | 时序数据库（指标历史、图表）      | 生产必需，可先用内置        | 3.3+（REST 端口 6041） |
| Docker（可选）       | 一键部署 MySQL/TDengine | 推荐                | 20.10+             |
| Nginx（可选）        | 反向代理 + HTTPS        | 可选                | 1.20+              |

> **最小化部署**
>
> ：不装 MySQL/TDengine，直接用内置 SQLite + 内置 TSDB，适合单机演示和小规模（<50 台设备）。

### 2.4 网络端口



| 端口         | 方向      | 用途                    |
| ---------- | ------- | --------------------- |
| **30821**  | 入站（浏览器） | Web 管理界面 / API        |
| **30001**  | 本机回环    | 内部节点通信（仅监听 127.0.0.1） |
| 161/UDP    | 出站      | SNMP 采集               |
| 514/UDP    | 入站      | Syslog 接收（如需日志采集）     |
| 1883/TCP   | 入站      | MQTT 节点上报（如启用节点功能）    |
| 3306       | 出站      | MySQL 连接              |
| 6041/TCP   | 出站      | TDengine REST 连接      |
| 25/465/587 | 出站      | 邮件 SMTP               |

## 三、快速部署（5 分钟）

### 3.1 下载安装包

从 Release 页下载对应平台包：



```
# Linux x86_64
wget https://gitee.com/ergn/netops-platform/releases/download/v2.1.9/netops-linux-amd64.zip
```



| 平台                  | 文件名                      |
| ------------------- | ------------------------ |
| Linux x86\_64       | netops-linux-amd64.zip   |
| Linux ARM64         | netops-linux-arm64.zip   |
| 麒麟 x86\_64          | netops-kylin-amd64.zip   |
| 麒麟 ARM64            | netops-kylin-arm64.zip   |
| 统信 x86\_64          | netops-uos-amd64.zip     |
| 统信 ARM64            | netops-uos-arm64.zip     |
| Windows x64         | netops-windows-amd64.zip |
| macOS Intel         | netops-darwin-amd64.zip  |
| macOS Apple Silicon | netops-darwin-arm64.zip  |

### 3.2 解压安装



```
unzip netops-linux-amd64.zip -d /tmp/netops
cd /tmp/netops
chmod +x install.sh
sudo ./install.sh
```

安装脚本会：



1. 解压到 `/opt/netops-platform/`

2. 创建 systemd 服务 `netops`

3. 设置开机自启并启动

### 3.3 访问

浏览器打开：`http://服务器IP:30821`

首次访问进入**初始化向导**：



1. 选择主数据库（默认内置 SQLite，生产建议 MySQL）

2. 选择时序数据库（默认内置，生产建议 TDengine）

3. 创建管理员账号

## 四、外部软件安装（生产环境）

### 4.1 MySQL 8.0（Docker 方式）



```
# 安装 Docker（如未安装）
curl -fsSL https://get.docker.com | sh
systemctl enable --now docker

# 启动 MySQL 8.0
docker run -d --name mysql \
  -p 3306:3306 \
  -e MYSQL_ROOT_PASSWORD='你的密码' \
  -e MYSQL_DATABASE=netops \
  -e TZ=Asia/Shanghai \
  --restart=always \
  mysql:8.0 \
  --character-set-server=utf8mb4 \
  --collation-server=utf8mb4_unicode_ci
```

验证：



```
docker exec -it mysql mysql -uroot -p -e "SHOW DATABASES;"
```

### 4.2 TDengine 3.x

#### Docker 方式（推荐）



```
docker run -d --name tdengine \
  -p 6041:6041 -p 6030-6040:6030-6040 \
  -v /opt/tdengine/data:/var/lib/taos \
  -v /opt/tdengine/log:/var/log/taos \
  -e TAOS_ROOT_PASSWORD='tadata' \
  --restart=always \
  tdengine/tdengine:3.3.2.0
```

#### 二进制方式



```
wget https://www.taosdata.com/assets-download/3.3/TDengine-server-3.3.2.0-Linux-x64.tar.gz
tar -zxvf TDengine-server-3.3.2.0-Linux-x64.tar.gz
cd TDengine-server-3.3.2.0
./install.sh
systemctl start taosd
```

验证 REST：



```
curl -u root:tadata -d "SELECT SERVER_VERSION()" http://127.0.0.1:6041/rest/sql
```

### 4.3 在初始化向导中填写



| 配置项     | 值         |
| ------- | --------- |
| 数据库类型   | MySQL     |
| 主机      | 127.0.0.1 |
| 端口      | 3306      |
| 用户      | root      |
| 密码      | 你设置的密码    |
| 数据库名    | netops    |
| TSDB 类型 | TDengine  |
| TSDB 主机 | 127.0.0.1 |
| TSDB 端口 | 6041      |
| TSDB 用户 | root      |
| TSDB 密码 | tadata    |

## 五、配置文件说明

配置文件位于 `/opt/netops-platform/config.yaml`，初始化向导自动生成。手动编辑示例：



```
app:
  name: NetOps
  jwt_secret: "随机字符串，重启后保持登录态"

server:
  host: "0.0.0.0"
  port: 30821
  internal_host: "127.0.0.1"
  internal_port: 30001
  # tls_cert: "/path/to/cert.pem"   # 启用 HTTPS
  # tls_key: "/path/to/key.pem"

database:
  type: mysql          # mysql | oracle | dm | kingbase | sqlite
  host: 127.0.0.1
  port: 3306
  user: root
  password: "你的MySQL密码"
  database: netops
  max_idle_conns: 10
  max_open_conns: 100
  log_level: 1

tsdb:
  type: tdengine       # tdengine | influxdb | builtin
  host: 127.0.0.1
  port: 6041
  user: root
  pass: tadata
  db: log

crypto:
  sm2_private_key: ""  # 留空自动生成
  sm2_public_key: ""
```

修改后重启：`sudo systemctl restart netops`

## 六、日常运维命令



```
# 查看状态
sudo systemctl status netops

# 查看日志
sudo journalctl -u netops -f

# 重启 / 停止
sudo systemctl restart netops
```

## 七、功能使用指南

### 7.1 设备管理



1. 进入 **设备管理 → 添加设备**

2. 填写：名称、IP、SNMP 端口（默认 161）、SNMP 版本（v2c）、共同体名（默认 public）

3. 保存后自动开始采集，可查看端口、流量、CPU / 内存

### 7.2 链路检测



1. **链路管理 → 添加链路**

2. 填写：源设备、目的 IP、阈值（普通文本，如 `100`）、持续时间（文本 + 单位选择：秒 / 分钟）

3. 链路中断 / 延迟超阈值自动触发告警

### 7.3 数据库监控



1. **数据库监控 → 添加实例**

2. 选择类型（MySQL/PostgreSQL/Oracle/ 达梦 / TDengine）

3. 填写连接信息，测试连接通过后保存

4. 系统每 30 秒采集：实例存活、连接数、容量、CPU、内存、运行时长

### 7.4 日志中心



* **设备日志**：接收 Syslog（UDP 514），支持按来源 / 级别 / 关键字过滤

* **采集任务日志**：查看每次采集任务的成功 / 失败、耗时

* 点击日志内容可弹出详情

### 7.5 告警与通知



1. **系统管理 → 通知渠道**：配置邮件 SMTP

* QQ 邮箱示例：SMTP 服务器 `smtp.qq.com`，端口 `465`，账号 `xxx@qq.com`，密码用**授权码**（非登录密码）

* 测试发送：填收件人 → 点 "发送测试"，收到即配置正确

1. **告警规则**：为设备 / 链路 / 数据库配置阈值

2. 所有告警自动发送到**所有已配置的通知渠道**

### 7.6 AI 巡检



1. **AI 巡检 → 立即巡检**

2. 系统自动汇总设备状态、日志、告警生成报告

3. 报告含：总体评价、发现问题、风险点、建议措施

### 7.7 在线升级



* **系统管理 → 在线更新**：自动检查 Release 新版本，一键升级 + 自动备份回滚

## 八、防火墙配置



```
# firewalld
sudo firewall-cmd --permanent --add-port=30821/tcp
sudo firewall-cmd --permanent --add-port=514/udp    # Syslog
sudo firewall-cmd --reload

# ufw (Ubuntu)
sudo ufw allow 30821/tcp
sudo ufw allow 514/udp
```

云服务器还需在控制台**安全组**放行 30821/TCP。

## 九、反向代理 HTTPS（可选）



```
server {
    listen 80;
    server_name netops.example.com;
    return 301 https://$host$request_uri;
}
server {
    listen 443 ssl;
    server_name netops.example.com;
    ssl_certificate     /path/to/cert.pem;
    ssl_certificate_key /path/to/key.pem;
    location / {
        proxy_pass http://127.0.0.1:30821;
        proxy_set_header Host $host;
        proxy_set_header X-Real-IP $remote_addr;
    }
}
```

## 十一、常见问题



| 问题         | 解决                                                     |
| ---------- | ------------------------------------------------------ |
| 页面打不开      | 检查 `systemctl status netops`、安全组是否放行 30821             |
| 设备离线       | 确认设备 SNMP 共同体名正确、防火墙放行 161/UDP                         |
| 邮件发不出      | QQ 邮箱必须用**授权码**，不是登录密码；确认 SMTP 端口 465                  |
| 时序库无数据     | 确认 TDengine 容器运行、6041 端口可连、密码正确                        |
| 数据库监控容量为 0 | MySQL 用 root 账号；TDengine 数据目录 `/opt/tdengine/data` 需可读 |
| 升级失败       | 自动备份在 `/opt/netops-platform-backup/`，可手动回滚             |
