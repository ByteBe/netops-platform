# 国产化适配说明

## 一、操作系统

### 1. 麒麟软件（Kylin V10）
```bash
# 1. 解压部署包
unzip netops-platform-linux-amd64.zip -d /opt/netops-platform
cd /opt/netops-platform

# 2. 赋权
chmod +x netops-server install.sh

# 3. 安装服务
./install.sh install

# 4. 状态
systemctl status netops
```

### 2. 统信 UOS（20/1060）
```bash
unzip netops-platform-linux-amd64.zip -d /opt/netops-platform
cd /opt/netops-platform
chmod +x netops-server install.sh
./install.sh install
```

### 3. ARM 架构（飞腾/鲲鹏）
编译目标为 `linux/arm64` 时请使用 arm64 部署包。当前默认包为 amd64（x86）。

## 二、国产化数据库

### 1. 达梦（DM8）
- 协议：兼容 Oracle 风格
- 初始化向导选择 `dm`
- 端口：默认 5236
- DSN 自动适配 Oracle 方言

### 2. OceanBase（MySQL 模式）
- 协议：MySQL
- 初始化向导选择 `oceanbase`
- 端口：默认 2881
- 自动建库

### 3. 人大金仓（KingbaseES V8）
- 协议：PostgreSQL
- 初始化向导选择 `kingbase`
- 端口：默认 54321

## 三、国密 TLS

### 1. HTTPS
在 config.yaml 中配置 SM2 证书路径：
```yaml
tls:
  cert: ./certs/sm2.crt
  key: ./certs/sm2.key
  sm2: true
```

### 2. MQTT（EMQX 国密）
- 启动 Mosquitto/EMQX 时启用 SM2 双向认证
- config.yaml：
```yaml
mqtt:
  tls_ca: ./certs/sm2_ca.crt
  tls_cert: ./certs/sm2_client.crt
  tls_key: ./certs/sm2_client.key
```

## 四、验证

```bash
# 查看版本
./netops-server -version

# 日志
journalctl -u netops -f
```
