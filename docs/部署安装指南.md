# NetOps 平台部署安装指南

## 一、环境要求

| 项目 | 最低配置 | 推荐配置 |
|---|---|---|
| 操作系统 | CentOS 7 / Ubuntu 20.04 / 麒麟 V10 / 统信 UOS | Ubuntu 22.04 LTS |
| CPU | 2 核 | 4 核 |
| 内存 | 2 GB | 4 GB |
| 磁盘 | 20 GB | 50 GB SSD |
| 网络 | 可访问被监控设备的 SNMP/SSH/数据库端口 | 同左 |

## 二、依赖软件清单

### 必需

| 软件 | 用途 | 说明 |
|---|---|---|
| MySQL 8.0+ | 平台元数据库 | 用户、设备、告警、配置 |
| netops-server | 主服务 | Go 静态编译二进制，无需运行时 |

### 可选

| 软件 | 用途 | 何时需要 |
|---|---|---|
| TDengine 3.x | 时序数据存储 | 需要历史曲线、监控大屏时 |
| Mosquitto | MQTT Broker | 分布式多级级联部署时 |
| wkhtmltopdf + 中文字体 | 巡检报告 PDF 导出 | 需要 PDF 报告时 |
| Ollama | 本地大模型 | 内网无外网、需要 AI 巡检时 |

### 不需要安装

Go 运行时、Node.js、Python、JVM、Nginx（前端由 Go 直接静态托管）。

## 三、快速部署

### 3.1 安装 MySQL

```bash
# Docker 方式
docker run -d --name mysql -p 3306:3306 \
  -e MYSQL_ROOT_PASSWORD=YourStrongPass \
  -e MYSQL_DATABASE=netops \
  --restart=always mysql:8.0

# 或裸装
yum install -y mysql-server   # CentOS
apt install -y mysql-server    # Ubuntu
```

创建库：
```sql
CREATE DATABASE netops DEFAULT CHARSET utf8mb4;
```

### 3.2 安装 TDengine（可选）

```bash
docker run -d --name td -p 6041:6041 -p 6030:6030 \
  --restart=always tdengine/tdengine:3.4.2.8
```

### 3.3 部署 netops-server

```bash
# 解压
mkdir -p /opt/netops-platform
tar -xzf netops-linux-amd64.tar.gz -C /opt/netops-platform
cd /opt/netops-platform
chmod +x netops-server

# 初始化配置
cat > config.yml << 'EOF'
server:
  port: 30821
mysql:
  host: 127.0.0.1
  port: 3306
  user: root
  password: YourStrongPass
  db: netops
tdengine:
  enabled: false
  host: 127.0.0.1
  port: 6041
  user: root
  password: taosdata
EOF
```

### 3.4 配置 systemd 服务

```bash
cat > /etc/systemd/system/netops.service << 'EOF'
[Unit]
Description=NetOps Platform
After=network.target

[Service]
Type=simple
WorkingDirectory=/opt/netops-platform
ExecStart=/opt/netops-platform/netops-server
Restart=always
RestartSec=5

[Install]
WantedBy=multi-user.target
EOF

systemctl daemon-reload
systemctl enable --now netops
```

### 3.5 验证

```bash
systemctl status netops
curl http://127.0.0.1:30821/
# 浏览器访问 http://服务器IP:30821，默认账号 admin / admin123
```

## 四、PDF 报告支持（可选）

```bash
# Ubuntu
apt install -y wkhtmltopdf fonts-wqy-zenhei fonts-noto-cjk xvfb

# CentOS
yum install -y epel-release
yum install -y wkhtmltopdf wqy-zenhei-fonts google-noto-sans-cjk-fonts xorg-x11-server-Xvfb

fc-cache -fv
```

## 五、Mosquitto MQTT（分布式部署，可选）

```bash
apt install -y mosquitto mosquitto-clients
mosquitto_passwd -c /etc/mosquitto/passwd netops

cat > /etc/mosquitto/conf.d/netops.conf << 'EOF'
listener 1883
allow_anonymous false
password_file /etc/mosquitto/passwd
EOF

systemctl restart mosquitto
```

## 六、AI 巡检（可选）

### 方式 A：云端 API（推荐）

无需安装任何软件。在「系统管理 → AI 配置」填入：
- DeepSeek：`https://api.deepseek.com`
- 通义千问：`https://dashscope.aliyuncs.com/compatible-mode/v1`
- 智谱 GLM：`https://open.bigmodel.cn/api/paas/v4`

### 方式 B：本地 Ollama（内网）

```bash
curl -fsSL https://ollama.com/install.sh | sh
systemctl enable --now ollama
ollama pull qwen2.5:7b
```

AI 配置填：
- BaseURL: `http://服务器IP:11434/v1`
- Model: `qwen2.5:7b`

## 七、防火墙开放端口

| 端口 | 用途 |
|---|---|
| 30821 | Web 控制台 |
| 1883 | MQTT（分布式时） |
| 514/UDP | 日志接收（syslog） |

## 八、升级

```bash
# 上传新包后
cd /opt/netops-platform
systemctl stop netops
tar -xzf netops-linux-amd64.tar.gz
systemctl start netops
```

数据库表结构自动迁移（GORM AutoMigrate），无需手动执行 SQL。

## 九、故障排查

```bash
# 查看服务日志
journalctl -u netops -f

# 查看应用日志
tail -f /opt/netops-platform/logs/app.log

# 端口占用
ss -tlnp | grep 30821
```
