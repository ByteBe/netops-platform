# NetOps 单机部署指南

## 1. 适用场景

单机部署适用于：
- 单机房 / 单园区网络
- 纳管设备 < 500 台
- 无上下级级联需求
- 快速试用 / 小规模生产

## 2. 系统要求

| 项 | 最低 | 推荐 |
|---|---|---|
| OS | Windows 10 / Ubuntu 20.04 | Windows Server 2022 / Ubuntu 22.04 |
| CPU | 2 核 | 4 核 |
| 内存 | 4 GB | 8 GB |
| 磁盘 | 20 GB | 100 GB SSD |
| 网络 | 可被监控设备 SNMP/ICMP 可达 | 同内网 |

## 3. Windows 部署

```
1. 解压 netops-platform-windows-amd64.zip
2. 双击 start.bat
3. 浏览器访问 http://127.0.0.1:30821
4. 按初始化向导配置数据库、时序库、管理员账号
```

目录结构：
```
netops-platform/
├── netops-server.exe    # 主程序
├── start.bat            # 启动脚本
├── config.yaml          # 配置
├── web/                 # 前端静态资源
├── data/                # SQLite 数据
└── logs/                # 日志
```

## 4. Linux 部署

```bash
unzip netops-platform-linux-amd64.zip -d /opt/netops-platform
cd /opt/netops-platform
chmod +x netops-server install.sh
./install.sh install
# 服务自动注册为 systemd
systemctl status netops
```

## 5. 初始化配置

首次启动进入向导：

1. **业务数据库**：默认 SQLite（data/netops.db），生产建议 MySQL
2. **时序数据库**：默认内置内存，生产建议 TDengine
3. **管理员账号**：admin / 首次登录强制改密

## 6. 日常运维

| 操作 | 命令 |
|---|---|
| 启动 | `netops-server.exe` 或 `systemctl start netops` |
| 停止 | `Ctrl+C` 或 `systemctl stop netops` |
| 日志 | `logs/` 目录 |
| 备份 | 系统管理 → 系统更新 → 下载备份 |
| 数据清除 | 删除 data/ 目录后重启，重新进入初始化 |

## 7. 端口

| 端口 | 用途 |
|---|---|
| 30821 | Web/API |
| 30001 | 内部服务 |

如需修改端口，编辑 config.yaml 后重启。

## 8. 升级

1. 下载新版 zip
2. 替换 netops-server（保留 data/ 和 config.yaml）
3. 重启服务
4. 系统管理 → 系统更新 → 执行迁移

## 9. 常见问题

- **端口被占用**：`fuser -k 30821/tcp`（Linux）或改 config.yaml
- **SNMP 不通**：检查设备团体名、防火墙、SNMPv3 认证配置
- **数据不显示**：确认采集任务已启用，等待 1-2 个采集周期
